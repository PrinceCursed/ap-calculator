# AP Calculator

`AP Calculator v2.dc.html` — основной макет. На холсте собраны светлая и тёмная темы, состояния расчёта и мобильные экраны шириной 390 px. `AP Calculator.dc.html` — обновлённая первая версия.

## Просмотр в браузере

Распакуйте архив и запустите из папки проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [основной макет](http://127.0.0.1:8000/AP%20Calculator%20v2.dc.html). Тёмные и светлые экраны расположены рядом. Для загрузки компонентов просмотра нужен интернет.

## Содержимое проекта

- `AP Screen.dc.html` и `AP Screen v2.dc.html` — компоненты экрана.
- `AP Kit.dc.html` — исходный набор компонентов.
- `emblems/` — 18 редактируемых SVG-эмблем.
- `uploads/` — визуальные референсы из исходного архива.

Расчёт в макете использует демонстрационные данные. Поиск, переключение фракций и тем, раскрытие строк и ручные начисления интерактивны. Загрузка и разбор реальных логов в исходном проекте представлены демонстрационными состояниями.
